# Root Cause Hypothesis

## Hypothesis

The classifier validated some package fields only after selecting an escalation path, while the CLI's global validation-error exit code overlapped `ACTION_REQUIRED`. Uncertainty remained a generic fallthrough category. Terminal-state reuse special-cased completion but not cancellation. Canonical and packaged resources were updated without regenerating the already-installed Governance Root.

## Supporting evidence

Independent Security and Autonomy reviewers reproduced every Red case at the exact same candidate. The stale installed manifest produced a deterministic Doctor failure and listed neither of the new resolution assets.

## Contradicting evidence

Routine L0/L1 work, valid exact L2/L3 packages, signed completion, durable pending UAT, first-consumer verification, Evidence, rollback, and package smoke were already Green and must remain unchanged.

## Falsification test

Run permanent tests in both risk-mismatch directions, malformed package shapes, L2/L3 uncertainty, unsigned/tampered cancellation reuse, current-Repo Doctor, and canonical/package/installed byte equality.

## Conclusion

Confirmed. The gaps were boundary-ordering, terminal-state asymmetry, and installed-copy drift rather than a need for more human approval.
