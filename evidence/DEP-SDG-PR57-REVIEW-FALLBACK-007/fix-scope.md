# Fix Scope

## Smallest sufficient change

Remove the external review provider as a sole availability authority without removing any security control or ignoring valid findings.

## Files or components in scope

Product contract, Policy Kernel mirrors, bilingual Product Charter, contract tests, and the approved decision record.

## Explicit non-scope

No provider login, paid plan, external access change, merge, tag, registry operation, or public release.

## Blast radius

Only review availability semantics change; findings handling and the independent signed Gate remain mandatory.
