# Baseline Provenance

The earlier ChatGPT deliverable was identified as `agentic-sdd-governance-v0.1.0.zip` / `v0.1.0-draft`. The conversation record confirms that it contained 56 source files, a Python CLI with `init`, `validate`, and `status`, governance/adapters/templates, and three passing tests.

The historical attachment endpoint remained visible in the owner's signed-in conversation, but automated retrieval was rejected by the expired/protected download path. No byte-for-byte source archive was therefore available inside this Work workspace.

`v0.2.0-experimental` is a clean canonical reconstruction that preserves the verified v0.1 capability baseline and implements the approved v0.2 governance/evidence plan. It must not be described as a textual patch against every original v0.1 file.

No BugEzy source code, private material, or third-party repository files were copied into this version. Evidence capture, DEP schemas, CLI behavior, templates, and redaction rules are independently implemented from the approved product requirements.
