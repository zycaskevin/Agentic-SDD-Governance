# Roadmap

## v0.2.0-experimental — current MVP

- Thin Policy Kernel and three governance Profiles.
- Progressive-disclosure Governance Skill and Codex/Hermes adapters.
- Debug Evidence Package schema, templates, state machine, local raw/shareable boundary.
- `evidence init|collect|redact|transition|verify|attach`.
- Collector contract and Browser/Playwright, Flutter/Logcat, Supabase/Docker, Terminal/Git playbooks.
- Paired screenshot-only versus evidence-driven benchmark harness.
- Tests for redaction, state gates, attachments, schemas, adapters, and progressive disclosure.

## v0.3 — enforcement hardening

- Pluggable redaction detectors and secret-scanner integration.
- Signed provenance receipts and tamper-evident event telemetry.
- CI adapters for GitHub/GitLab and protected evidence-policy files.
- Work Claim TTL and External Action Queue enforcement.
- Stronger JSON Schema validation with optional dependency.

## v0.4 — collectors and interoperability

- Native Playwright trace summarizer and HAR body allowlist.
- Flutter/Android structured parsers and test-result normalization.
- Supabase local-development collector that fails closed on production ambiguity.
- Spec Kit and Superpowers integration adapters.

## v0.5 — empirical pilots

- Historical replay, sandbox product, then opt-in live shadow pilots.
- Holdout tasks and independent evaluation.
- Publish only measured claims with uncertainty, costs, failure cases, and risk escapes.

No roadmap item silently changes L0–L3 authority or permits production action.
